Secure Offline Codebase Diagnostics & Testing

FuncPilot parses and analyzes your JavaScript & TypeScript code structures locally, building absolute privacy barriers. It detects code smells, calculates complex block depths, and compiles high-fidelity Jest and Vitest suites—without calling any external servers, without requiring API keys, and at 10x the speed of cloud-based engines.

01

Scan & Parse AST

FuncPilot scans project files recursively using high-speed static glob tools. It constructs abstract syntax tree (AST) profiles using @babel/parser and ts-morph, indexing classes, methods, constructors, parameters, and async profiles natively.

  • High-speed AST profiling
  • Maps recursive exports
  • Dynamic glob file routing
02

Diagnose Code Quality

Runs structural metrics analysis on your methods and functions. Natively flags code smells, high complexity scores, oversized functions, and high parameter levels with immediate actionable refactoring suggestions.

  • Automated complexity rules
  • Refactoring warnings & hints
  • Zero configuration needed
03

Generate & Run Specs

Generates mock-ready, clean Jest or Vitest boilerplates matching your method signatures. Launches unified local child processes via Execa, executing tests dynamically and formatting terminal coverage reports.

  • Mocks matching imports
  • Unified Jest / Vitest integration
  • Interactive CLI dashboard

Pipeline Architecture

Inside FuncPilot's highly modular and local-first static processing engine.

Step 1

Source Files

Local JS / TS codebases scanned by recursive glob crawlers.

Step 2

AST Parser

Uses @babel/parser and ts-morph to extract structural profiles.

Step 3

Diagnostics Engine

Checks complexity metrics and flags long code smell warning blocks.

Step 4

Boilerplate Engine

Generates mock-configured spec files for Jest or Vitest.

Start Testing Instantly

Get up and running with the global FuncPilot CLI in less than a minute.

1

Install Globally

Download and register the CLI globally on your workstation via npm.

Terminal 
npm install -g funcpilot
2

Initialize Your Project

Run the interactive setup wizard in your project root to auto-detect environments and create `.funcpilotrc`.

Terminal 
funcpilot init
3

Generate Tests

Instantly scan your codebase and construct unit test templates inside your output directories.

Terminal 
funcpilot generate-tests src/

Building FuncPilot

FuncPilot was created to provide developers with a fast, private, and zero-configuration environment for unit testing boilerplate setups. By parsing TypeScript and JavaScript files locally through abstract syntax trees (ASTs), it completely eliminates the need for slow AI networks or external API key dependencies, securing raw source codes with native privacy guidelines.
